# Security

The current alpha version is maintained on `main`. No security support for older
releases is promised. Benchmark formulas do not intentionally execute supplied
code or retrieve remote resources during evaluation.

After publication, use GitHub's private vulnerability reporting if the repository
owner enables it. Otherwise contact a maintainer through an available private
channel before sharing sensitive details. Do not include credentials or private
data in public issues. Ordinary numerical/formula bugs belong in the bug template.
